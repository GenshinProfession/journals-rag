课题设计的背景
[字体:默认, 字号:12.0pt, 左对齐] 随着如今人们经济水平的提高，生活已不仅仅只是衣食住行，还有各种各样的业余兴趣，不少的人也开始种植花草。***********************植物对于人们是不可缺少的，现代人把侍弄花草当成一种生活的乐趣，甚至是一种减压方法。但是植物的栽种有时候不仅仅只是浇水施肥，对于不同的植物，它所需要的生长环境是不一样的，其中土壤的湿度对于植物的生长也起着一定的决定性作用。而且不同植物对于土壤湿度的需求也不同[1]。所以土壤湿度的检测是必不可少的，目前主要利用的是土壤湿度传感器进行土壤湿度的检测，其体积小，方便高效，是目前使用最多的检测[2]。
[字体:默认, 字号:12.0pt] 另外，目前无线网络的也逐渐应用于各个领域中，无线网络带给人们很多方便，不再局限于方寸之地，有很大的发展空间，给许多的领域带来新生。本文所设计的智能土壤湿度检测器也用到了无线网络通信，有数据获取实时方便的优点。
课题设计的目的和意义
[字体:默认, 字号:12.0pt] 无论植物的大小多少，*******，首先必须要有严谨的研究方式。所以科研工作必须是严谨的，效率、准确度是非常重要的，实时而精确地获取土壤湿度数据对于植物的科研工作具有重要意义[3]。
[字体:默认, 字号:12.0pt] 另外，当今社会，几*******手机来获得湿度数据给研究土壤湿度带来了方便，使得获取数据有着高效，便捷的优点。而本设计通过无线网络来连接单片机与手机，使得其拥有远距离传输数据的优点。

import numpy as np
import cv2
import sys
def saliency(src):
    src_mean = cv2.mean(src)
    print src_mean
    print np.asarray(src_mean).shape
    src_gaussian = cv2.GaussianBlur(src, (3, 3), 0)
    print src_gaussian.shape
    return cv2.absdiff(src_mean, src_gaussian)
if __name__ == '__main__':

        img = cv2.imread(sys.argv[1])

    img_saliency = saliency(img)
    img_saliency = img_saliency[:,:,1]
    cv2.imshow('src', img)
